# 《污染边境》V2 后续路线图

> **Archived / Historical**
>
> 该文档描述 `archive/v2-world` 分支中的连续世界方向，不代表当前 `main` 的游戏规则。

> 本文档只定义版本方向、目标和边界，不代表对应功能已经实现。
> 当前事实以 [`current-game-status.md`](./current-game-status.md) 和实际代码为准。

## 1. 长期定位

《污染边境》是一个以静默圣遗物为家园锚点、以远征探索为主要行为、世界会因为玩家行为产生持续污染与生态变化的 2D 回合制生存探索游戏。

主要参考可以包括《饥荒》《星露谷物语》、Minecraft 的程序世界，以及 SCP / 克苏鲁式异常世界，但不会完整移植这些作品的系统。

需要形成辨识度的核心关系是：

```text
出去
→ 做出选择
→ 对世界留下影响
→ 回来
→ 再次面对一个已经发生变化的世界
```

核心关键词：

```text
安全区
远征
世界记忆
污染
生态变化
```

## 2. 设计原则

### 2.1 世界是持久的

玩家离开一个地方以后，它仍然存在。资源、污染、尸体、巢穴、建筑和作物应逐步成为世界记忆的一部分。

### 2.2 保留风险决策，不保留副本结构

V2 继续强调准备、风险收益、深入或返回、携带能力、回程压力和死亡损失，但不再依赖单次副本和固定撤离点。

### 2.3 探索是主要行为

玩家的大部分主动玩法应发生在安全区之外。基地的作用是提高探索距离、携带能力、生存稳定性、净化能力和资源处理能力。

### 2.4 静默圣遗物是安全锚点

静默圣遗物不是普通 Buff 建筑，也不是绝对无敌区。近期继续使用明确半径和污染阈值；未来高污染、高疯狂怪物或异常可以突破保护。

长期空间层次：

```text
核心安全区
→ 基地缓冲区
→ 正常危险世界
```

### 2.5 世界记得玩家

玩家行为应逐渐留下资源变化、污染、尸体、巢穴变化、建筑和作物等痕迹，并反过来改变后续探索。

### 2.6 数值守恒

继续坚持“数值不会无原因产生或消失”：

```text
HP 损失 → 世界污染
怪物肉污染 → 圣遗物或玩家
玩家抗性承受污染 → 明确的污染去向
```

发生净化、衰减或损耗时，也应给出世界观和规则上的转化解释。

### 2.7 保留成熟系统

不因 V2 重写已经稳定工作的格子移动、战争迷雾、方向视野、敌人 AI、战斗、尸体切割、疯狂、疯狂抗性、圣遗物净化和巢穴。新系统优先组合现有能力。

## 3. 核心循环目标

```text
静默圣遗物 / 基地区域
→ 准备远征
→ 离开安全区
→ 探索持久世界
→ 发现地形、资源、怪物、巢穴和异常
→ 采集、绕行、战斗或深入
→ 获得资源
→ 判断继续还是返回
→ 主动返回静默圣遗物
→ 储存、净化、恢复和建设
→ 下一次向更远区域探索
```

“返回”必须成为玩家基于生命、抗性、饥饿、背包、路径和危险作出的自然决定，而不是地图上另一个撤离点。

## 4. 系统优先级

### 4.1 永久污染：V2.1 已建立

现有基础：

```text
玩家 HP 损失 + 怪物 HP 损失
→ sceneMadness
```

V2.1 已把战斗实际生命损失同步记录为具有格子位置并永久保存的动态污染，同时保留 `sceneMadness` 兼容统计。

V2.1.2 已将静默圣遗物的精神保护、饥饿保护与世界安全范围统一为 8 格，同时保留独立的 `safetyRadius` 空间规则字段；该调整不改变污染持久化或怪物 AI。

第一阶段只建立“世界污染总账”，不要求同步完成生态变化。

未来关系：

```text
战斗 / 死亡 / 巢穴 / 异常行为
→ 区域污染
→ 怪物、巢穴、资源、植物、事件和地形变化
→ 新的危险与资源
→ 改变玩家探索路线
```

### 4.2 远征闭环

清除正常流程中的撤离点和成功撤离目标，让饥饿成为持久的远征续航值，定义背包、基地库存、死亡损失以及回到圣遗物后的结算。

### 4.3 最小基地

近期只做功能设施：

```text
静默圣遗物
储物设施
种植地
必要时增加简单工作设施
```

暂不做墙、门、房间、家具、屋顶、旋转、耐久、复杂寻路和防守模拟。

### 4.4 采集、种植与养殖

优先级：

```text
采集 > 种植 >>> 养殖
```

- 采集：即时获取资源并驱动地图探索。
- 种植：把远征中的不确定资源转化为基地里的稳定供给，服务更长距离远征。
- 养殖：属于后期自动化与高级资源系统，在时间、食物、设施、消耗和生态成熟前不展开。

### 4.5 世界区域

近期不追求无限世界或更多 Noise。优先让世界形成玩家可辨识的“东边森林”“北部石山区”等区域。

长期生成结构：

```text
Macro Region
→ Elevation / Moisture / Corruption
→ Terrain
→ Resources
→ Ecology
→ Entities / Events
```

## 5. 版本路线

## V2.0 — Persistent World MVP

状态：已实现。

已建立：

- 100×100 Seed 持久世界；
- 八类地形；
- 静默圣遗物地图实体；
- 安全起步区、饥饿保护和污染阈值保护；
- 树木、石矿、木材和石材；
- 玩家位置及资源变化持久化；
- 复用现有战斗、敌人、巢穴和迷雾。

当前边界：

- 饥饿不持久；
- 怪物和巢穴不是生态生成；
- `sceneMadness` 仍是运行快照统计；V2.1 另以 `dynamicCorruption` 建立永久世界污染；
- 旧 V1 外出容器和结算代码仍在；
- 没有正式基地功能或新的 Demo 目标。

## V2.1 — Persistent Pollution

状态：已实现。

核心目标：

> 让世界第一次真正记住玩家。

已实现：

- 战斗实际 HP 损失产生的污染永久保存；
- 污染具有空间位置；
- 离开并返回该区域后污染仍存在；
- 保存与加载结果一致；
- 地图以简单、可读的方式反馈污染程度；
- 污染数值来源可追踪，保持 1:1 转移原则。
- 基础污染与动态污染分层，战斗不改写 Seed 世界；
- 玩家和怪物分别落在自身损血时的战斗坐标快照；
- overkill、逃跑和死亡均按实际损血处理；
- 稀疏 WorldSave 数据、旧存档迁移和世界身份隔离。

第一阶段明确不做：

- 污染驱动完整怪物生态；
- 植物异变链；
- 地形永久变种；
- 污染扩散或复杂衰减模拟；
- Chunk 重构；
- 基地建设或种植。

建议验收问题：

- 同一场战斗的玩家和怪物实际 HP 损失是否准确进入对应区域？
- 刷新、离开和再次进入后污染是否保持一致？
- 过量伤害是否被错误计入？
- 污染是否发生重复结算？
- 玩家能否从地图反馈理解哪里发生过污染？

## V2.2 — Expedition Loop

核心目标：

> 完成从副本搜打撤到连续世界远征的转换。

重点：

- 清理正常流程中的撤离点概念；
- 移除成功撤离次数作为核心目标；
- 定义新的 Demo 目标；
- 饥饿持久化；
- 回到圣遗物作为远征自然结束点；
- 明确死亡后的资源损失和恢复位置；
- 明确随身背包与基地库存边界；
- 强化继续深入还是返回的判断；
- 评估并拆分 `activeExpedition` 的兼容职责。

新目标应围绕探索距离、资源带回、区域发现、基地成长和污染变化，而不是撤离次数。

## V2.3 — Minimal Base

核心目标：

> 让返回基地具有稳定且可理解的价值。

第一批设施：

- 储物；
- 种植区；
- 必要时加入一个简单工作设施。

基地服务远征，不让远征退化为纯粹的盖房材料收集。

## V2.4 — Farming

核心目标：

> 建立第一条稳定生产循环。

最小循环：

```text
探索获得种子或原始资源
→ 返回基地
→ 播种
→ 世界回合推进
→ 成熟
→ 收获食物
→ 支持更远远征
```

暂不加入营养类型、复杂烹饪 Buff 和食物腐败链。

## V2.5 — Pollution Ecology

进入条件：V2.1 的永久污染已经被验证有趣、可读且没有明显数值失控。

让污染逐步影响：

- 怪物类型与强度；
- 巢穴密度；
- 植物和资源；
- 随机事件；
- 地形视觉状态。

目标闭环：

```text
玩家活动
→ 污染
→ 生态变化
→ 世界危险和收益变化
→ 改变玩家决策
```

## V2.6 — World Regions

重点不在扩大地图，而在形成：

- 有辨识度的区域；
- 区域资源；
- 区域风险；
- 区域生态；
- 特殊地点。

玩家应能形成地理记忆，而不是只看到均匀随机噪声。

## 6. 世界尺寸与 Chunk

当前 100×100 足够验证 V2 玩法。近期继续使用有限但较大的持久世界，以形成路线、污染历史、区域故事和“这是我的世界”的感觉。

Chunk 可在未来作为内部技术结构，例如 16×16 格，用于：

- 存档分区；
- 实体休眠；
- AI 激活；
- 污染更新；
- 资源恢复；
- 局部生态模拟。

近期约束：

- Chunk 不成为玩家可见规则；
- 不为 Chunk 提前重构当前可工作的 100×100 世界；
- 不进入无限世界或完整流式加载。

## 7. 饥饿定位

V2 中饥饿主要承担“远征续航值”：

```text
圣遗物保护范围 → 移动不消耗饥饿
离开保护范围 → 移动消耗饥饿
食物 ≈ 可以探索的额外距离
```

它应帮助玩家判断“还能走多远、是否有足够资源返回”，而不是发展为复杂生理模拟。

近期不加入：

- 口渴；
- 蛋白质、维生素等营养类型；
- 复杂烹饪 Buff；
- 食物腐败链。

V2.2 必须解决当前每次运行时启动都会重新初始化饥饿的 V1 语义。

## 8. 更远期方向

暂不进入近期开发：

- 养殖；
- 多个圣遗物、升级与过载；
- 多基地；
- 大型异常地点；
- Boss、NPC 和剧情；
- 昼夜与天气；
- 高级制作和装备构筑；
- 无限世界；
- 完整 Chunk 流式加载。

## 9. 近期执行约束

在 V2.1 评审通过前：

- 不实现永久污染；
- 不实现种植；
- 不实现建筑；
- 不进行 Chunk 重构；
- 不实现污染生态；
- 不实现养殖；
- 不因文档整理删除 V1 兼容代码；
- 不重写成熟的战斗、敌人 AI、迷雾、尸体切割、疯狂或巢穴系统。
