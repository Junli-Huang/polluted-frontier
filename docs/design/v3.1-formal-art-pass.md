# V3.1 正式美术资源化检点

## 目标

把 V3 远征主线从程序占位美术切换为静态正式资源驱动，同时保持格子、视野、回合和碰撞等玩法逻辑不变。

## 本次替换

- 主菜单：正式荒野背景、雾层与材质化按钮。
- 庇护所：正式地下空间背景、圣遗物、食物、异变肉与种植资源。
- 户外地图：地表、障碍、玩家、敌人、巢穴、尸体、撤离点、未探索迷雾全部改用静态美术资源。
- 战斗：移除“猎 / 异”程序占位字，改用角色/敌人美术。
- UI：面板、HUD、按钮、弹窗统一为磨损金属/皮革式暗色框架。

## 保留的程序层

- 格子坐标与移动规则。
- 敌人方向视野的几何裁剪与危险范围，因为它属于战术信息层而不是角色美术。
- 状态数值、进度条宽度与迷雾可见性判定。

## 验收标准

1. 页面上不再使用圆点/文字字符充当玩家、敌人或战斗角色美术。
2. 地图未探索区域使用纹理迷雾资源，而不是纯黑矩形作为最终表现。
3. 庇护所的核心功能卡片具有明确美术主题而非默认 Web 面板。
4. 桌面和移动端仍可完整操作。
5. `npm test` 与 `npm run build` 通过。

## 第二轮：正式界面化

- 户外探索从网页双栏布局收拢为地图主画面 + 战术覆盖层，HUD 下沉为指挥条。
- 庇护所重新编排为基地控制台：圣遗物成为视觉中心，幸存者状态、仓储、种植、外出与目标围绕核心组织。
- 战斗界面升级为全屏对峙构图，角色美术占主视觉，日志与操作位于下方。
- 格子、敌人视野、迷雾判定继续保持精确，不牺牲可读性换氛围。
- UI 统一使用磨损边框、暗色材料、少量警戒色，不再使用明显 Web Card 语言。
