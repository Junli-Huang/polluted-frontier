# 《污染边境》V2.0 持久世界 MVP

> **Archived / Historical**
>
> 该文档描述 `archive/v2-world` 分支中的连续世界版本，不代表当前 `main` 的游戏规则。

## 目标

V2.0 将主流程从“庇护所 UI → 单次外出地图”改为直接进入一个由 Seed 决定的持久世界。静默圣遗物、资源和玩家位置都是世界的一部分。

## 数据架构

`WorldMap` 是可由 Seed 重建的静态数据，包含世界尺寸、地形、圣遗物、资源和出生点。100×100 世界不会把全量静态格子重复写入 `localStorage`。

`WorldSave` 只保存可变数据：

- `worldId / seed / version`
- `playerPosition`
- `inventory.wood / inventory.stone`
- `resourceStates`
- `discoveredRelicIds`
- `turn`

## 地形生成

第一阶段使用海拔、湿度和污染三类确定性噪声：

1. 海拔决定水、浅水、陆地和石山区。
2. 湿度决定草地、土地、森林和泥地。
3. 污染叠加距圣遗物距离，形成由低到高的风险梯度。

已实现：`grass / dirt / forest / water / shallow_water / rock / mud / corrupted`。雪地和冰面属于第二阶段。

## 静默圣遗物

- 生成在世界中心附近，并强制整理周围起步区。
- 默认保护半径 5 格。
- 范围内污染不高于 100 时，环境疯狂结算被屏蔽。
- 范围内移动不消耗饥饿。
- 玩家站在圣遗物格按 E 打开管理界面，可恢复抗性、净化异变肉并查看木材/石材。

## 资源

- 树木生命 2，耗尽后掉落 2 木材，预留恢复回合字段。
- 石矿生命 3，耗尽后掉落 2 石材，MVP 不恢复。
- 每次采集推进一个地图回合。
- 存档只记录发生变化的资源状态。

## 与 V1 系统的关系

- 战斗、敌人状态机、方向视野、巢穴和战争迷雾继续复用。
- 旧固定敌人布局以圣遗物附近为中心平移到新世界。
- 旧庇护所实现暂时保留用于存档兼容，但主菜单不再进入庇护所 UI。
- 新世界不生成撤离点，探索不再以撤离作为常规结束方式。

## 存档迁移

旧 V1 存档保留生命、疯狂、抗性、异变肉等角色数据，并补建 `world`。当 `worldId + seed` 一致时合并可变状态；世界身份变化时保留角色层、重建世界层。旧 `activeExpedition` 与新世界地图 ID 不一致时不恢复。

## 验证

- 同 Seed 完整复现地形、圣遗物、出生点与资源。
- 起步区可通行、低污染且位于保护范围。
- 八类地形和两类基础资源能够生成。
- 世界存档不重复保存静态格子。
- 资源耗尽状态可以恢复。
- 世界身份变化时安全重建世界状态。
- V1 配置、存档、战斗、敌人 AI、迷雾和巢穴测试保持通过。
