# 《污染边境》V2.1 持久污染

> **Archived / Historical**
>
> 该文档描述 `archive/v2-world` 分支中的连续世界版本，不代表当前 `main` 的游戏规则。

## 1. 版本目标

V2.1 让战斗第一次在持久世界中留下可返回、可观察的永久痕迹：

```text
战斗实际 HP 损失
→ 损血者的世界格
→ dynamicCorruption
→ WorldSave
→ 刷新、离开并返回后仍然存在
```

## 2. 污染分层

```text
baseCorruption + dynamicCorruption = effectiveCorruption
```

- `baseCorruption`：Seed 与世界生成规则决定的 `tile.pollution`，静态且可复现。
- `dynamicCorruption`：玩家进入世界后由战斗实际 HP 损失产生的持久数据。
- `effectiveCorruption`：统一读取接口返回的逻辑和值。

V2.1 不改写基础污染，也不让动态污染参与环境疯狂伤害、圣遗物保护、怪物生成、资源生成或地形判定。

V2.1.1 将静默圣遗物的空间安全规则与本污染层进一步明确拆分：

- V2.1.2 将精神保护与饥饿保护的 `radius` 从 5 调整为 8；
- `safetyRadius = 8` 只约束怪物移动、追击、攻击意图和巢穴产怪位置；
- 两个字段当前数值相同，但继续保持独立，方便未来重新拆分空间安全与玩家保护规则；
- 旧 V2.1.1 的默认 5/8 配置组合会迁移为 8/8，其他自定义保护半径不被改写；
- 安全区不读取或清除 `dynamicCorruption`，也不阻止新的战斗损血写入世界。

## 3. 产生与落点

- 只有战斗造成的实际 HP 损失产生动态污染。
- 玩家损血写入玩家发生损血时的世界格。
- 怪物损血写入怪物发生损血时的世界格。
- 接敌时将双方世界坐标快照到战斗上下文，后续不从已变化对象反推。
- 实际 HP 损失与新增动态污染严格 1:1。
- overkill 只按目标剩余 HP 计入。
- 逃跑前、玩家死亡前已经发生的损血不会回滚。
- 圣遗物范围内发生的战斗遵守同样规则。
- 圣遗物只保护玩家免受当前环境污染影响，不阻止世界记录生命损失。

`sceneMadness` 暂时继续同步累计同一份实际损血，用于兼容旧统计与运行快照；胜利、失败和逃跑回调不再次结算污染。

## 4. 存档

`WorldSave.version = 2`，新增稀疏结构：

```json
{
  "dynamicCorruption": {
    "50,50": 8,
    "50,51": 15
  }
}
```

- 0 不保存。
- 同格多次损血持续相加。
- 数值不限制为 0～100。
- 不自然衰减、扩散、自动清除或因返回圣遗物重置。
- V2.0 存档缺少字段时迁移为空对象。
- `worldId` 或 `seed` 不一致时重建世界层，旧世界动态污染不会迁移到新世界。

## 5. 地图反馈

动态污染按真实数值保存，地图只进行四档离散表现：

- `0`：无叠加；
- `0～25`：极淡暗紫红；
- `25～50`：可见叠加；
- `50～100`：明显叠加；
- `100+`：严重叠加。

叠加绘制在地形之上、实体和战争迷雾之下，并配合低对比腐化纹路。未探索格仍被黑色迷雾遮挡；敌人、资源、尸体和圣遗物保持在污染层之上。

运行时 `getCorruptionAt(x, y)` 可用于调试读取：

```text
baseCorruption
dynamicCorruption
effectiveCorruption
```

正常 HUD 不常驻显示具体数值。

## 6. 明确边界

V2.1 不实现：

- 污染扩散、衰减、迁移或净化；
- 污染生态、怪物增强、巢穴变化或资源变化；
- 永久改变 Terrain Type；
- Chunk、基地、种植、养殖或饥饿持久化；
- `activeExpedition` 重构；
- 完整死亡掉落重做。

后续由 V2.5 Pollution Ecology 评估动态污染对世界规则的反向影响。
