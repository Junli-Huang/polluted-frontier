# 《污染边境》当前游戏状态

> 本文档是当前 `main` 实现状态的单一事实来源；实际代码行为优先于本文档，历史设计文档不代表当前规则。

- 当前版本：V3.0.0-dev Expedition Rebuild
- 当前基线：V1 最后稳定远征结构（`1dfe0efaaf07846efc4973f335672d5cc70c83a8`，`V1.3.9 Simple Fog Mask`）
- 公开体验：[GitHub Pages](https://junli-huang.github.io/polluted-frontier/)

## 1. 当前定位

保护区 UI 与单次户外远征重新成为当前主流程。V2 连续世界已归档，后续将选择性移植永久资源、永久属性和环境内容。

```text
主菜单
→ 保护区查看状态、库存、装备、圣遗物与种植
→ 开始一次户外远征
→ 探索、随机事件、怪物行动与独立战斗
→ 切割尸体并决定继续深入或撤离
→ 撤离成功或远征失败结算
→ 返回保护区
```

默认目标：成功撤离 3 次并累计带回至少 12 块异变肉。默认失败条件：外出失败达到 3 次，或保护区储备粮与异变肉同时耗尽。

## 2. 当前已实现

### 2.1 主菜单、保护区与存档

- 主菜单提供开始、继续、配置、关于和重置存档；开始或继续进入保护区，不直接进入户外世界。
- 保护区显示生命、疯狂、疯狂抗性、食物、逐块异变肉、固定装备、Demo 目标和最近结算。
- 静默圣遗物是保护区 UI 中的交互设施，可恢复疯狂抗性、完全或部分净化指定异变肉。
- 灰麦种植格按外出次数推进生长。
- 生命、保护区物品、疯狂、疯狂抗性、圣遗物净化值、种植、目标与统计跨远征保存。
- 户外运行快照保存地图、Seed、随机状态、玩家、怪物、尸体、迷雾、事件与巢穴进度；正常结算后清除。

### 2.2 单次户外远征

- 地图支持 10×10～50×50，默认 20×20；包含玩家出生点、撤离点、障碍、固定/随机怪物与固定 Seed。
- 三态战争迷雾：未探索、已探索记忆、当前可见；已探索区离开视野后变暗。
- 移动、等待、切割和撤离读条按离散地图回合推进怪物行动。
- 饥饿每次远征初始化，只在实际移动时消耗；归零后移动造成生命伤害。
- 环境污染按时间消耗疯狂抗性，溢出部分增加疯狂；战斗、事件、暂停与页面不可见期间不推进。
- 8 个数据驱动随机事件支持条件、权重、选择与即时结果。

### 2.3 怪物、巢穴与战斗

- 怪物统一状态机：`Idle / Wander / Alert / Chase / AttackIntent / Return / Cooldown / Dead`。
- 普通怪物具有四方向朝向、可配置扇形视野、障碍遮挡、警觉、追踪、攻击意图、返回与冷却。
- 腐化巢穴属于统一怪物实体，可按配置产出子怪；被破坏后停止产出。
- 接敌后进入独立回合制战斗，支持攻击、防御、道具和逃跑。
- 胜利后地图留下尸体；站在尸体格可切割，获得带独立污染值的异变肉。

### 2.4 撤离、失败与返回

- 在撤离点完成读条后成功撤离，保存本次带回的异变肉与剩余生命，展示结算后返回保护区。
- 战斗死亡、饥饿死亡或其他失败进入失败结算，按 V1 规则处理临时战利品与生命，再返回保护区。
- 返回保护区后可以再次开始远征；刷新页面不会切换到 V2 连续世界。

### 2.5 工具、表现与部署

- 配置系统支持表单、校验、JSON 导入导出、恢复默认与可视化地图编辑。
- 地图编辑器支持固定对象、随机怪物区域、Seed、50 步撤销/重做与草稿试玩。
- 22 个程序化 WAV 音效覆盖移动、战斗、怪物状态、切割、污染、圣遗物与撤离。
- 桌面和移动端具有响应式布局；Vite 构建产出 GitHub Pages 静态文件。
