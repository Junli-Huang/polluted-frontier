# 《污染边境》V3 远征主线重建

## 当前定位

V3 以 V1.3.9 的成熟短远征结构重新建立开发基线：玩家在保护区 UI 中准备，开始一次户外远征，完成探索、战斗、切割与撤离，再回到保护区结算。

这不是删除 V2 后简单回退版本号。Git 历史继续保留 V2，当前开发版本为 `V3.0.0-dev · Expedition Rebuild`。

## V2 归档

- V2.1.2 完整实现保存在 `archive/v2-world` 分支和 `v2.1.2` 标签。
- `v2.1.1` 标签指向真实的 V2.1.1 提交。
- V2 的连续世界、静默圣遗物地图实体、世界资源和持久污染仍可用于比较与选择性移植。
- 当前主线不兼容 V2 世界存档；检测到此类存档时会安全创建新的远征存档，不进行复杂迁移。

## 后续组合方向

```text
V1 短远征结构
+ 环境障碍
+ 资源采集
+ 永久库存与属性
+ 重新设计的持久污染
```

近期优先保持一局远征短、清楚、可完整结算。后续将逐步评估并移植树木与巨石障碍、木石采集、永久资源库存、永久物品与属性，以及适合短远征结构的污染持久化。

100×100 连续世界、地图圣遗物安全区、世界坐标持久化和连续世界资源总账不会进入近期主线。

## 本阶段边界

本阶段只恢复可靠的 V1 远征基线，不新增树木、巨石、采集、永久资源、永久属性、新污染区域、新地图生成、基地建设、种植扩展或养殖内容。
